# MachineOps Workbench 1.0.0

MachineOps Workbench 1.0 is the first complete supported release of the
simulator-only job execution and diagnostics console.

## Highlights

- Original cross-platform Avalonia desktop with light and dark themes.
- G-code import, source-line validation, and XY toolpath preview.
- Controller-based ASP.NET Core API with external DTOs and Problem Details.
- Explicit Dapper and PostgreSQL persistence with reviewed migrations.
- Deterministic TCP controller simulator, fault scenarios, and replay files.
- Live SignalR state with bounded rendering and authoritative HTTP resync.
- Durable alarms, idempotent acknowledgement, optimistic concurrency, and a
  transactional outbox.
- Paged search across jobs, runs, alarms, and protocol messages.
- Windows installer and portable ZIP.
- Debian package and Linux portable archive.
- Docker Compose demonstration, checksums, SBOM, and security scans.

## Supported scope

The supplied simulator is the only supported controller. This release does not
control physical machinery and does not claim complete GRBL compatibility.
Authentication, TLS, package signing, macOS, ARM, and automated retention are
also outside the v1.0 scope.

## Upgrade

Back up the PostgreSQL volume before upgrading. Database migrations are applied
on API startup and are forward-only. Desktop packages can be installed over an
older version. See
[upgrade and rollback](../deployment/upgrade-and-rollback.md) for the full
procedure.

## Verification

The tagged release is built with warnings as errors. Its release record covers
all automated tests, real PostgreSQL integration tests, Docker Compose, the
service-side demonstration, Windows and Ubuntu installation and removal,
coverage, dependency review, secret scanning, and container vulnerability
scanning.

The measured results are in
[release evidence](../testing/release-evidence.md).
